# 外來飲食的在地化

> 許多臺灣小吃源自外地，傳入後再依臺灣的食材與口味改良。（推論，歸納自 [[src-觀光署-小吃飲品]]）

## 說明

依觀光署介紹，外來來源可分為幾類（來源：[[src-觀光署-小吃飲品]]）：

| 來源地 | 小吃 |
|---|---|
| 上海 | 生煎包、小籠包 |
| 福建 | [[蚵仔煎]]、胡椒餅 |
| 山東 | 蔥抓餅 |
| 日本／日治時期 | 車輪餅、刨冰（含 [[芒果冰]]）；天婦羅（原文只說名稱來自日本關西，是否由日本傳入屬推論） |
| 1949 年後外省移民 | [[牛肉麵]] |
| 美國 | [[鹽酥雞]]（靈感來自美式炸雞） |
| 其他菜系 | [[刈包]]（即荷葉夾） |

- 在地化也會「再出口」：臺灣牛肉麵 1970 年代隨移民到美國加州，1980 年代以「加州牛肉麵」之名進入中國大陸（來源：[[src-維基百科-牛肉麵]]）
- 外來飲食要能在地化，也要社會條件改變：臺灣早期因感念耕牛不吃牛，牛肉麵要等 1949 年後外省移民才出現（來源：[[src-維基百科-牛肉麵]]）
- 連臺灣原創的[[珍珠奶茶]]也有外來影響：有學者認為奶茶源於英國，香港絲襪奶茶在 20 世紀中期傳入臺灣，間接影響珍奶的發明（來源：[[src-維基百科-珍珠奶茶]]）
- 在地化的方式：小籠包加入絲瓜、瓠仔等當令食材；牛肉麵把四川的紅燒牛肉加上麵條（來源：[[src-觀光署-小吃飲品]]）

## 相關小吃

- [[牛肉麵]]：一道菜變成一碗麵
- [[蚵仔煎]]：福建傳來，用臺灣產的蚵仔
- [[鹽酥雞]]：美式炸雞的臺灣版
- [[刈包]]：餐廳的荷葉夾變成街頭小吃

## 給初學者的重點

- 臺灣小吃是「移民的料理」：不同時代來的人帶來家鄉味（推論）
- 傳進來之後會改變：換食材、改吃法（來源：[[src-觀光署-小吃飲品]]）
